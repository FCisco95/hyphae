The post-payout web release is live. It adds claim waiting/recovery, a visible connected wallet, wallet records, Solana Actions and epoch schedule notices. Per-member rules-test and hold checklists are private; public contribution/payment receipts and aggregates remain available.

- [Release CI](https://github.com/FCisco95/hyphae/actions/runs/38140495535) and [following documentation CI](https://github.com/FCisco95/hyphae/actions/runs/38141589367) passed. Local release checks: 1,731 tests passed, three gated tests skipped; typecheck, lint, Drizzle, 84 Postgres 17 tests and 16 contract hashes passed.
- [Claim and privacy reviews](REVIEWS.md) accepted. The claim transaction builder, program and payout/scoring rules did not change in this release.
- Fresh signed-out desktop 1920×1080 and 390-pixel phone smoke passed: home, proof/trust, epoch-2 settlement and four paid rows, claim picker, wallet record, Actions GET/OPTIONS, API docs and OpenAPI. No horizontal overflow or page errors. Read-only wallet smoke made zero signing calls.
