## What works

The epoch page shows a "Schedule change" panel right after the "Pilot amendment" panel when the epoch window (`closes_at − opens_at`) differs from `config.payload.epoch.durationSeconds` by at least one minute. It shows nothing when the duration is missing, not a number, or not positive, or when the window matches. Epoch 2 as the API serves it today (2026-10-02 → 2026-10-10, 604800 s) shows the panel.

No API, core schema, database or config change. `LooseEpochV1` types `config.payload` as `Record<string, unknown>`, so the web reads `epoch.durationSeconds` defensively. The link is built from `APP_REPO` (the same base `trust.ts` uses), not a new constant: a new GitHub constant in `links.ts` would fail the repo-allowlist test in `links.test.ts`.
