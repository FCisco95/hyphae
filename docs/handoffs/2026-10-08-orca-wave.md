## Lessons

- Five agents running full test suites at once pinned an 8-core laptop at 100% CPU and caused vitest RPC timeouts. Cap heavy sessions at two and run vitest with `--maxWorkers=2`.
- Orca's Codex launcher on Windows quoted `-m` so `cmd` rejected it; launch Codex in a terminal with plain arguments and attach the dispatch with `--terminal`.
